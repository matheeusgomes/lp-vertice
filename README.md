# Vértice Pages — Landing page de vendas

Landing page estática pronta para Vercel ou GitHub Pages.

## Antes de publicar

WhatsApp já configurado: 55 19 98387-5892. Os serviços não exibem preços; o investimento é negociado após o briefing. Revise as condições antes de publicar. Os projetos mostrados são conceitos visuais, não páginas demonstrativas navegáveis nem clientes reais.

## Vercel

Importe o repositório na Vercel. O arquivo `vercel.json` já aponta a saída para a pasta `dist`.

## GitHub Pages

Envie o projeto para um repositório com branch `main`. Em **Settings → Pages**, selecione **GitHub Actions**. O fluxo incluído publicará a pasta `dist` automaticamente.

## Personalização

- Textos e estrutura: `dist/index.html`
- Cores e layout: `dist/styles.css` e `dist/vertice.css`
- WhatsApp e interações: `dist/script.js`

O formulário prepara uma mensagem no WhatsApp; o visitante precisa confirmar o envio no aplicativo. Não há banco de dados, Analytics, painel, checkout ou serviço de SEO. Domínio e hospedagem não estão incluídos nos preços apresentados. O projeto é estático e não precisa de instalação nem build. Para visualizar localmente, abra dist/index.html.
